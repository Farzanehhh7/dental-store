# Dental Store

Specialized dental equipment and supplies e-commerce store (Persian / RTL UI, English code).

- `PROMPT.md`: master build prompt
- `docs/DATA_AND_ADMIN_SPEC.md`: source of truth for data model, search, admin dashboard and SEO

Current state: a Vite + React + TypeScript + Tailwind starter with mock data (home, category with filters, product with variant selector). No backend yet.

## Run

```
npm install
npm run dev
```
